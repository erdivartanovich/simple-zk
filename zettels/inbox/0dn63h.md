# IFS

IFS (Internal Field Separator) is a shell variable defining the characters used to split input into fields, commonly spaces, tabs, and newlines.

Example:
IFS=$'\n\t' sets the shell’s internal field separator to only newline and tab. That means word splitting on unquoted expansions will not split on spaces, reducing bugs when values contain spaces. It’s a common safety tweak when combined with set -euo pipefail.
