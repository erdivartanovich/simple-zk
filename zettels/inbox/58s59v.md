# nvim cheatsheet: navigate changes and history


#nvim #cheatsheet

Session edits (per buffer, no plugin):
- `g;` / `g,` — older / newer change position (`3g;` jumps 3 back)
- `:changes` — list, `>` marks position
- `` `. `` — jump to last change; `'.` line-wise
- `gi` — resume insert where you left it
- `<C-o>` / `<C-i>` — jump list (cross-file)

History:
- `:Undotree` — undo branches panel (bundled 0.12 plugin)
- `u` / `<C-r>`, `g-` / `g+` — undo/redo, by time
- `:earlier 5m` / `:later 5m` — time travel (undofile persists across sessions)

Vs git: `:Gvdiff` (this buffer, side-by-side), `:Gdiff` (all changes → quickfix), `git difftool -d` (whole tree).
