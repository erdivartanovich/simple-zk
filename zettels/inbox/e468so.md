# nvim cheatsheet: find files and grep


#nvim #cheatsheet

Native finding, no picker plugins.

- `:Fd pat` / `:F pat` — fd across cwd + ~/.config; 1 hit opens directly, more → quickfix
- `:find <Tab>` — wildmenu completion; path/wildignore auto-synced from .gitignore (lua/find-ignore-list.lua)
- `:Grep pat` — LIVE-updating quickfix while typing (rg via grepprg, respects glob excludes)
- `:Ngrep pat` — vimgrep over $NOTES_DIR
- `:Yazi` / `:Y` — floating yazi, open picked file; `:YaziCwd` / `:Yc` also cd
- `:Ex` / `:Vex` / `:Sex` — netrw (stock); inside: `<CR>` open, `v` vsplit, `o` split, `t` tab, `p` preview, `-` up-dir
- `,,` or `<leader>,` — :ls + :b buffer switch
- `%%` (cmdline) — expands to current file's dir; `<leader>e.` / `es` / `ev` / `et` — edit sibling file (split/vsplit/tab)
