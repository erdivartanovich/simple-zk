# Bash - Set positonal arguments
#source

To manually set or overwrite positional arguments inside a Bash script or function, use the built-in:
`set -- ` command

```bash
greet() {
  echo "hello $1 and $2 and $3"
}
set -- "apple" "banana" "cherry"

# now: $1=apple, $2=banana $3=cherry $#=3
```



## Why Use --?
The double dash -- signals the end of command options to the set builtin. Without it, if your first value starts with a dash (e.g., -v), Bash will mistake it for a shell option instead of an argument string

## This will clear all the arguments:

```bash
set --
```
