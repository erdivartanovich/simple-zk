# Bash Heredoc Guide
#source

A **Heredoc** (Here Document) is a form of input redirection in Bash that allows you to pass multi-line blocks of text or code directly into a command. It is widely used in shell scripts to generate files, print long text blocks, or send multiple commands to remote servers.


## 1. Basic Syntax
The syntax begins with a command followed by the redirection operator `<<` and a custom **delimiter** token (commonly `EOF` or `END`). You close the block by placing the exact same delimiter on its own line at the end.

```bash
cat << EOF
This is line one.
This is line two.
EOF
```


## 2. Variable and Command Expansion

### Unquoted Delimiter (Default)
If you leave the delimiter unquoted, Bash will automatically **expand variables and execute command substitutions** inside the text block.

```bash
USER_NAME="Alex"

cat << EOF
Hello \$USER_NAME,
Today's date is: \$(date)
EOF
```

### Quoted Delimiter (Literal Mode)
If you place single or double quotes around the initial delimiter, Bash treats the entire block as **literal text**. Variables and commands will not expand.

```bash
cat << 'EOF'
The variable \$USER_NAME will not expand here.
The command \$(date) will print as plain text.
EOF
```


## 3. Handling Indentation with `<<-`
By default, the closing delimiter cannot have any leading spaces or tabs. Adding a minus sign (`<<-`) tells Bash to **strip leading tab characters** from both the content lines and the closing delimiter. This helps keep code clean inside loops or functions.

```bash
if true; then
	cat <<- EOF
	This line has a leading tab, but it will print flush-left.
	The closing EOF must also be prefixed by a tab.
	EOF
fi
```
> **Note:** This strictly works with **tab characters**, not spaces.


## 4. Common Use Cases

### Saving Content to a File
Pair a Heredoc with file redirection (`>` to overwrite, `>>` to append) to generate configuration or script files.

```bash
cat << EOF > /tmp/config.json
{
  "status": "active",
  "port": 8080
}
EOF
```

### Running Commands Over SSH
Stream multiple statements to a remote server over a single SSH connection.

```bash
ssh user@remote-server << 'EOF'
cd /var/www/html
git pull
systemctl restart nginx
EOF
```

### Assigning a Multi-line String to a Variable
Capture a multi-line block of text into a single variable using a subshell command substitution.

```bash
MY_TEXT=\$(cat << 'EOF'
Line A
Line B
Line C
EOF
)

echo "\$MY_TEXT"
```


## 5. Heredoc vs. Herestring (`<<<`)
While a Heredoc (`<<`) handles multi-line streams, a **Herestring (`<<<`)** passes a **single string or single variable** directly to the standard input of a command.

```bash
# Convert a single string to uppercase using tr
tr 'a-z' 'A-Z' <<< "hello world"
```
