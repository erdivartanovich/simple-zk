# Vim - Exrc
#source

The exrc option in Vim and Neovim allows the editor to look for and load local configuration files
(like .exrc, .vimrc, or .nvim.lua) in the current working directory upon startup. This enables
project-specific settings, though it can pose security risks if untrusted local files contain
malicious automatic commands. 

N.B
Useful for setting make/makeprg to compile the project using specific command/compiler.
Why not using filetype autocmd?
In my understanding, filetype autocmd with pattern e.g. 'typescript', 'typescriptreact',
will be evaluated when opening file with that specific filetype.
