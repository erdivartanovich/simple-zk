# Pinentry

Helper program used by GnuPG to securely prompt you for passphrases
There are different variants:

- pinentry-tty — Plain text terminal
- pinentry-curses — Ncurses TUI version
- pinentry-gtk — GTK GUI version
- pinentry-qt — Qt GUI version
- pinentry-rofi — Rofi version
- pinentry-gnome3, pinentry-mac, etc.
